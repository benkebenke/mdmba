# mdmba

**Cav Connect** is a mobile web prototype that rewards UVA fans with points for checking in at spring sports games, with a multi-sport bonus, tiers, and a rewards catalog. It's the NBK Prime team project for Darden; the app lives in [`cav-connect/`](cav-connect/README.md).
